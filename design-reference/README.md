# Binder Design Reference Pack

This folder is the visual and behavioral reference for extending Binder's UI.

## Capture details

- Captured from the current Expo web build on 1 September 2026.
- Viewport: 390 x 844 px.
- Long screens use full-page capture so all current content is visible.
- The conversation screen uses viewport capture to preserve its fixed composer layout.
- These are implementation references, not proposed redesigns.
